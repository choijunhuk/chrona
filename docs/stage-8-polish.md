# Stage 8 — 디자인 폴리싱 + 마감 작업

> **선행**: Stage 7 완료 및 머지
> **브랜치**: `stage-8-polish`
> **목적**: 기능은 다 됐다. 이제 "매일 쓰고 싶은 앱"으로 만든다. 그리고 개인용 앱에서 진짜 중요한 백업을 붙인다.

---

## 1. 모션 폴리싱

### 1-1. 전수 점검
모든 화면 전환·상태 변화를 훑으면서 아래를 확인한다:
- [ ] `duration` 기반 easing이 남아있는 곳 → 스프링으로 교체
- [ ] JS 스레드 애니메이션 → worklet으로 이관
- [ ] 화면 이탈 시 정지하지 않는 애니메이션 → `useFocusEffect` 추가
- [ ] `LayoutAnimation` 사용처 → Reanimated `Layout`으로 교체

### 1-2. 햅틱 전수 적용
```
selection : 탭 전환, 날짜 선택, 뷰 전환, 토글
impact    : 일정 생성/삭제, 드래그 스냅
success   : 과제 완료, 타이머 완료, 알람 해제
warning   : 오프라인 쓰기 차단, 유효성 실패
```
설정에서 햅틱 전체 끄기 옵션 제공.

### 1-3. 화면 전환
- expo-router의 기본 전환을 커스텀 (`animation: 'fade_from_bottom'` 등)
- 모달(`/timer`, `/event/[id]`)은 아래에서 올라오는 스프링
- `/alarm-ring`은 전환 애니메이션 없음 (즉시 표시)

### 1-4. stagger 통일
리스트 진입 애니메이션을 전부 20ms 간격으로 통일. 이미 적용된 곳과 안 된 곳을 맞춘다.

## 2. 라이트 테마

Stage 2에서 `useTheme()`만 만들고 다크 값만 반환했다. 이제 라이트를 채운다.

```ts
light: {
  bg:        '#F7F8FA'
  surface:   '#FFFFFF'
  surfaceAlt:'#EFF1F5'
  border:    '#DFE2E9'
  text:      '#1A1D24'
  textSub:   '#5E6473'
  textDim:   '#9BA1B0'
  accent:    '#5566F0'   // 밝은 배경에선 살짝 어둡게
  // palette 8종도 라이트용으로 명도 조정
}
```

- 설정: 시스템 따름 / 항상 다크 / 항상 라이트
- **`/alarm-ring`은 테마와 무관하게 항상 다크.** 새벽에 흰 화면이 뜨면 눈이 아프다
- 전환 시 깜빡임 없도록 확인

## 4. ★ 백업 / 내보내기

**개인용 앱에서 가장 중요한 기능일 수 있다.** Supabase 무료 티어는 장기 미사용 시 프로젝트가 일시정지되고, 실수로 날릴 수도 있다.

### 4-1. JSON 내보내기
- 전체 데이터(events, overrides, reminders, categories, semesters, alarms, sessions, settings)를 하나의 JSON으로
- `expo-sharing`으로 공유 시트 → 구글 드라이브·카톡 등으로 저장
- 파일명: `chrona-backup-YYYYMMDD.json`

### 4-2. JSON 가져오기
- 파일 선택 → 검증 → **덮어쓰기 전 확인 다이얼로그**
- 스키마 버전을 JSON에 포함하고, 버전 불일치 시 거부

### 4-3. .ics 내보내기
- 표준 iCalendar. rrule을 그대로 실을 수 있다
- 구글 캘린더 등으로 옮길 수 있는 탈출구
- 종일 일정은 `VALUE=DATE`로 (시각 없이)

### 4-4. 자동 백업 알림 (선택)
- 월 1회 "백업한 지 30일 됐어요" 알림
- 재계산 파이프라인에 합류
