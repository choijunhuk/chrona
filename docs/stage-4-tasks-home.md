# Stage 4 — 과제 D-day + 홈 탭

> **선행**: Stage 3 완료 및 머지
> **브랜치**: `stage-4-tasks-home`
> **목적**: 앱을 열자마자 "오늘 뭘 해야 하는지"가 보이게 만든다. 과제 마감 관리를 붙인다.

---

## 0. 이 스테이지에서 하지 않는 것

- 집중 타이머 실제 동작 (Stage 6) — 홈에 버튼만 두고 비활성
- 통계 위젯 (Stage 7)
- 시간표 (Stage 5) — 홈의 "다음 수업"은 Stage 5 이후 채워진다

## 1. 작업 순서

### 1-1. 과제(task) 데이터 처리

`events.kind = 'task'`. Stage 1에서 컬럼은 이미 있다.

**과제는 일반 일정과 다르게 다룬다:**
- 시작 시각이 없다. `due_at`만 있다
- 캘린더에 시간 블록으로 그리지 않고, **해당 날짜 셀 상단에 D-day 칩**으로 표시
- 완료(`is_done`) 상태를 가진다

`src/domain/task.ts`:
```ts
daysUntilDue(dueAt: Date, now: Date, tz: string): number  // 날짜 기준 (시각 무시)
dueUrgency(days: number): 'overdue' | 'today' | 'soon' | 'normal'
  // overdue < 0 / today = 0 / soon <= 3 / normal
```

**D-day 계산은 "날짜 차이"로 한다.** 시각까지 계산하면 "D-1인데 23시간 남음"처럼 직관과 어긋난다.

### 1-2. 계단식 알림

과제 생성 시 기본으로 3개의 `reminders`를 자동 생성한다:

```
마감 3일 전  09:00 기준   mode: 'notify'
마감 1일 전  09:00 기준   mode: 'notify'
마감 3시간 전              mode: 'notify'
```

- 각각 개별 on/off 가능
- 사용자가 원하면 마지막 것만 `alarm` 모드로 승격 가능
- `offset_minutes` 기준은 `due_at` (Stage 3 §1-2 규칙)
- **이미 지난 단계는 예약하지 않는다** (내일 마감인 과제를 지금 만들면 "3일 전"은 스킵)

기본 3단계 값은 `app_settings`에 넣지 않고 상수로 고정하되, 과제별로 편집 가능하게 한다.

### 1-3. 과제 편집 화면

`/event/[id]`를 재사용하되 `kind`에 따라 폼이 달라진다.

```
과제 모드
  제목
  마감  [날짜] [시각]  ← 시각 미지정 시 23:59
  과목  [카테고리 선택 또는 시간표 과목 연결]
  메모
  알림  [3일 전 ✓] [1일 전 ✓] [3시간 전 ✓]
  완료  [ ]
```

- 일정↔과제 전환은 생성 시에만 선택 (수정 중 변경 금지 — 데이터가 꼬인다)
- 시간표 과목과 연결하면 색상·카테고리를 상속

### 1-4. 과제 목록

`/more` 또는 홈에서 진입하는 `/tasks`:
- 미완료 → 마감 임박 순
- 완료 → 별도 섹션, 접힘, 최근 7일만
- 완료 체크 시 햅틱 + 스트라이크스루 애니메이션 후 이동
- 지난 과제(overdue)는 최상단에 `danger` 색으로 고정

### 1-5. ★ 홈 탭 (`/(tabs)/index`)

**정보 밀도가 높되 스크롤 없이 한 화면에 핵심이 다 보여야 한다.**

```
┌────────────────────────────────────┐
│ ⚠️ 알람 권한이 해제되었습니다  [수정] │  ← 깨졌을 때만 (Stage 3 §1-9)
├────────────────────────────────────┤
│  8월 23일 일요일                    │
│  오늘 일정 3개 · 과제 2개            │
├────────────────────────────────────┤
│  다음 일정                          │
│  ┃ 14:00  알고리즘 스터디            │
│  ┃ 2시간 12분 후 · 산학협력관         │
├────────────────────────────────────┤
│  마감 임박                          │
│  [D-1 운영체제 과제] [D-3 보고서]    │
├────────────────────────────────────┤
│  오늘 남은 일정                      │
│  14:00  알고리즘 스터디              │
│  19:00  저녁 약속                   │
├────────────────────────────────────┤
│        [ 집중 시작 ]                │  ← Stage 6까지 비활성
└────────────────────────────────────┘
```

세부 규칙:
- **"다음 일정"의 남은 시간은 1분마다 갱신**하되, 타이머가 아니라 `useEffect` + 60초 interval. 화면 포커스 잃으면 정지 (마스터 §6)
- 오늘 일정이 없으면 "오늘은 일정이 없어요" + 내일 첫 일정 미리보기
- D-day 칩: `today`는 accent, `overdue`/`soon`(≤1일)은 danger, 나머지는 surfaceAlt
- 진입 시 섹션별 stagger 애니메이션

### 1-6. 캘린더에 과제 표시

- 날짜 셀 상단에 작은 D-day 도트 (일정 색상 점과 구분되는 형태 — 사각형 등)
- 하단 시트 목록에서는 **일정보다 위에** 과제 섹션
- 완료된 과제는 `textDim`으로 흐려짐

### 1-7. 탭 바 재구성

Stage 2까지는 캘린더가 첫 화면이었다. 이제:
```
홈 | 캘린더 | 시간표(빈 화면) | 알람 | 더보기
```
시간표 탭은 자리만 만들고 "Stage 5에서 구현" 플레이스홀더.

## 2. 검증

| # | 항목 | 통과 기준 |
|---|---|---|
| 1 | 과제 생성 | D-day 계산 정확 |
| 2 | 계단식 알림 3건 자동 생성 | 예약 목록에서 확인 |
| 3 | 내일 마감 과제 생성 | "3일 전" 단계 스킵됨 |
| 4 | 과제 완료 체크 | 알림 자동 취소 |
| 5 | overdue 과제 | 홈·목록 최상단, danger 색 |
| 6 | 홈 "다음 일정" 남은 시간 | 1분마다 갱신, 이탈 시 정지 |
| 7 | 권한 경고 배너 | 권한 끄면 표시, 고치면 사라짐 |
| 8 | 자정 넘김 | 홈이 새 날짜로 갱신 |
| 9 | 시간대 경계 | 23:50에 D-1인 과제가 00:10에 D-0으로 |

**9번 주의**: 날짜 기준 D-day이므로 자정을 넘으면 숫자가 바뀌어야 한다. 자정 앵커에서 홈 캐시를 무효화한다.
