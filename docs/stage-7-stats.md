# Stage 7 — 통계

> **선행**: Stage 6 완료 및 머지. **`focus_sessions` 데이터가 최소 1~2주 쌓인 뒤 시작하는 것을 권장.**
> **브랜치**: `stage-7-stats`
> **목적**: "계획한 시간 vs 실제 집중한 시간"을 보여준다. 이게 이 앱에서 가장 쓸모 있는 회고 도구다.

---

## 0. 원칙

**보여줄 수 있는 걸 다 보여주지 않는다.** 통계 화면은 지표를 늘릴수록 아무도 안 본다.
아래 4개만 만든다. 더 필요하면 나중에 추가.

---

## 1. 지표 4종

### 1-1. 주간 카테고리별 시간 배분 (도넛)
- 소스: `events` 중 시각이 있는 일정의 duration을 카테고리별 합산
- 반복 일정은 전개해서 실제 회차만 (override 반영)
- 이번 주 / 지난 주 전환

### 1-2. 계획 vs 실제 (막대)
- **계획**: `events`의 시각 있는 일정 duration 합
- **실제**: `focus_sessions`의 `ended_at - started_at` 합 (completed 무관)
- 요일별 2색 막대. 차이가 한눈에 보이게
- 이게 이 화면의 주인공이다

### 1-3. 과제 완료율
- 이번 달 기준: 완료 / 전체
- 마감 전 완료 vs 마감 후 완료 구분
- 단순 링 프로그레스

### 1-4. 연속 집중 일수 (스트릭)
- `focus_sessions`가 하루 1건 이상 있는 날의 연속 일수
- 현재 스트릭 + 최고 기록
- **과도하게 강조하지 않는다.** 스트릭 압박은 역효과. 작게 표시

---

## 2. 구현

### 2-1. 집계 로직 (`src/domain/stats.ts`)

**순수 함수. 여기서 계산하고 UI는 그리기만.**

```ts
weeklyCategoryBreakdown(occurrences, categories, range): CategorySlice[]
plannedVsActual(occurrences, sessions, range): DailyComparison[]
taskCompletionRate(tasks, range): { total, done, onTime, late }
focusStreak(sessions, today, tz): { current: number; best: number }
```

- 전부 단위 테스트를 붙인다
- 시간대는 `resolveTimezone(settings)` 사용 (Stage 1 §1-6)
- **주 경계는 사용자 설정(주 시작 요일)을 따른다**

### 2-2. 성능

- 집계는 클라이언트에서. Supabase RPC를 쓰지 않는다 (오프라인 지원 + 데이터가 작음)
- 계산 결과는 `useMemo` + 쿼리 캐시. 화면 진입마다 재계산 금지
- 데이터가 커지면(1년치) 범위를 제한한다. 기본 조회 범위는 최근 90일

### 2-3. 차트

`victory-native` (Skia 기반). 이유:
- JS 기반 차트 라이브러리는 스크롤과 함께 움직일 때 프레임이 깨진다
- Skia는 네이티브 렌더링이라 부드럽다

규칙:
- 색상은 반드시 디자인 토큰에서 (마스터 §5.2)
- 애니메이션은 진입 시 1회만. 반복 애니메이션 금지 (배터리)
- 축 라벨 최소화. 숫자를 빽빽하게 넣지 않는다

### 2-4. 화면

```
/stats  (더보기 하위 또는 별도 탭)

  이번 주                    [< >]
  ┌─────────────────────────┐
  │   계획 vs 실제 (막대)     │
  └─────────────────────────┘
  ┌─────────────────────────┐
  │   시간 배분 (도넛)        │
  │   학교 12h · 과제 6h ...  │
  └─────────────────────────┘
  ┌───────────┬─────────────┐
  │ 과제 완료율 │ 연속 집중    │
  │   8/10     │   5일       │
  └───────────┴─────────────┘
```

- 좌우 화살표로 주 이동
- 데이터가 없는 주는 "아직 기록이 없어요"
- 로딩은 스켈레톤

### 2-5. 홈에 요약 한 줄 (선택)

```
이번 주 집중 8시간 32분 · 계획 대비 71%
```
탭하면 통계 화면으로. 홈이 이미 빽빽하면 넣지 않는다.

## 3. 검증

| # | 항목 | 통과 기준 |
|---|---|---|
| 1 | 카테고리 합산 | 수동 계산과 일치 |
| 2 | 반복 일정 포함 | 전개된 회차만 계산 |
| 3 | 휴강(override 취소) 회차 | 통계에서 제외 |
| 4 | 계획 vs 실제 | 세션 시간과 일치 |
| 5 | 주 경계 | 주 시작 요일 설정 반영 |
| 6 | 스트릭 | 하루 건너뛰면 리셋 |
| 7 | 자정 경계 걸친 세션 | 시작일 기준으로 귀속 |
| 8 | 빈 주 | 크래시 없이 빈 상태 표시 |
| 9 | 90일치 데이터 | 화면 진입 1초 이내 |
| 10 | 오프라인 | 캐시로 렌더링 |
